# Aramesh Music Academy Website

This is a Django-based web application built for the **Aramesh Music Academy**, providing an online presence for managing teachers, gallery displays, class schedules, and student inquiries.
you can view the website https://aramesh-academy.ir

## Features

- **Teacher Directory:** Profiles and biographies for music instructors.
- **Gallery:** Showcase of academy activities and media.
- **Schedules:** Management and display of course sessions and music classes.
- **Contact:** Integrated contact form for prospective students.
- **Localization:** Uses `django-jalali` for Persian calendar support.

## Tech Stack

- **Framework:** [Django 5.2.14](https://www.djangoproject.com/)
- **Database:** SQLite (default)
- **Localization:** `django-jalali`
- **Media Handling:** `Pillow`
- **Security:** `django-simple-captcha`
